# Tools

## block_map.py

Prints the map of code blocks of a module compiled with Visual C++. The
linker aligns code of each object file and each COMDAT section at 16 bytes
and fills gaps with `int 3` (`0xCC`), so a block of procedures between such
gaps is either one `.cpp` file (compiled without `/Gy`) or a single COMDAT
procedure: an inline function emitted out of line, a template instance or a
procedure generated by the compiler.

For each block the script lists its procedures with files and declarations
from sources, and notes blocks with procedures of several files. At the end
it lists blocks of each file and marks single procedure blocks of `.cpp`
files, which are probably inline or template functions.

```bash
python tools/block_map.py <BldMystery>/src/BBLibc/asm/raw.txt --asm src/BBLibc/asm/code.str --src <BldMystery>/src
```

- `raw.txt` is the disassembly of the module (from BldMystery).
- `--asm` adds procedures from `PROC` labels of `code.str` or `native.asm`,
  can be given several times.
- `--src` adds files and declarations from `Entry point` comments of
  sources, `--module` sets the module name (default: `module.txt` next to
  `raw.txt`).
